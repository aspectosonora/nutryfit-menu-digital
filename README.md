# Nutryfit — Menú digital

Menú digital mobile-first de Nutryfit, preparado para consultar productos, personalizar pokes, crear un pedido y enviarlo por WhatsApp.

## Funcionalidad

- Categorías visuales y búsqueda por categoría.
- Detalle de productos con tamaños, opciones, notas y cantidad.
- Configurador completo de poke.
- Carrito y resumen de pedido.
- Entrega para recoger o a domicilio.
- Envío del pedido por WhatsApp.
- Información de la nutrióloga, mapa, contacto y redes sociales.

## Tecnología

Sitio estático construido con HTML, CSS y JavaScript.
